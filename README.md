A premium, modern personal portfolio website for **Raja Mohan**, a Python Full Stack Developer Fresher based in Chennai, India.

## 🚀 Live Demo
[View Portfolio](https://rajamohan-portfolio.vercel.app)

## ✨ Features
- 🌙 Dark Theme with Glassmorphism
- 🎨 Animated Gradient Background
- ⌨️ Typing Animation (Hero Section)
- 🖱️ Scroll Reveal Animations
- 📊 Animated Skill Progress Bars
- 🃏 Interactive Project Cards
- 📱 Fully Responsive (Mobile, Tablet, Desktop)
- 🔝 Sticky Navigation with Active Link Highlight
- 💌 Contact Form
- ⬆️ Back-to-Top Button

- **Hero** – Introduction with typing animation and floating tech badges

- **Skills** – Categorized skills with animated progress bars
- **Projects** – Portfolio Website & To-Do Web Application
- **Education** – B.E. Mechanical Engineering + Python Full Stack Training
- **Internship** – VME Foundry Equipments, Coimbatore
- **Soft Skills** – Critical Thinking, Problem Solving, Teamwork, Communication
- **Achievements** – Key milestones and accomplishments
- **Online Profiles** – GitHub, LinkedIn, Portfolio
- **Contact** – Contact form, email, phone, location
